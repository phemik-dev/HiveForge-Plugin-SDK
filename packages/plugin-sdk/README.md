# @hiveforge-ai/dsh-plugin-sdk

One-package entry point for the HiveForge Plugin SDK.

```bash
npm install @hiveforge-ai/dsh-plugin-sdk@next
```

It re-exports the portable contract, headless host registry, durable work-fact store, and atomic-file transport. Install `@hiveforge-ai/dsh-plugin-example-transform@next` separately for the reference plugin.
